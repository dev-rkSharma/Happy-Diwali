# Diwali wish

A responsive Diwali greeting with animated fairy lights, glowing diyas, a floral rangoli, rising firework rockets, sparkling fountains, and personalized sharing. An animated SVG scene depicts Lord Ram, Mata Sita, and Lakshman returning to an illuminated Ayodhya, with a path of diyas and falling flower petals. No build step or installation needed. Open `index.html` to preview.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `diwali-wish`.
2. Upload **the contents of this folder** (`index.html`, `style.css`, `script.js`, and `.nojekyll`) to the repository root.
3. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/ (root)**, then click **Save**.
5. Once GitHub finishes publishing, share `https://YOUR-USERNAME.github.io/diwali-wish/`.

Use the page's **Share wish** button to create a personalized link. For example, `https://YOUR-USERNAME.github.io/diwali-wish/?to=Priya` opens with “For you, Priya”. On mobile the button opens the native share menu when supported; otherwise it copies the link.

If uploading this whole folder into an existing Pages repository, its address will end with `/diwali%20wish/` instead.

Google Fonts provides the two optional typefaces; system font fallbacks work offline. All festive artwork is generated locally with SVG, CSS, and canvas. Animation respects reduced-motion preferences and can be paused with the button at the top.
